# QA Testing Project

Repozytorium zawiera materiały przygotowane podczas nauki testowania oprogramowania.

## Zakres projektu

Projekt obejmuje:

- przypadki testowe
- testy negatywne
- raporty błędów
- analizę wymagań
- testowanie aplikacji webowych
- podstawy automatyzacji testów

---

# Technologie i narzędzia

- TestRail
- Jira
- Selenium
- Postman
- GitHub
- Chrome DevTools

---

# Struktura repozytorium

## test-cases
Przypadki testowe przygotowane dla aplikacji webowych.

## bug-reports
Raporty błędów i zgłoszenia defektów.

## test-analysis
Analiza wymagań i przeglądy dokumentacji.

## screenshots
Zrzuty ekranu z narzędzi testerskich.

## automation
Materiały związane z automatyzacją testów.

---

# Przykładowe scenariusze testowe

- logowanie użytkownika
- wysyłanie wiadomości email
- walidacja formularzy
- testy regresji
- analiza wartości brzegowych
